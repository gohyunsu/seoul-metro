MISSING VALUES

결측 0건, 대체 0건

숫자로 해석되지 않는 시간대 값은 결측으로 집계하지만, 이번 파일에서는 발견되지 않았습니다. 따라서 fillna(0)은 실행 경로에 있어도 실제 대체한 셀은 없습니다.

ZERO COUNTS

0명은 결측이 아닙니다

0은 해당 시간대에 기록된 유효 수요일 수 있으므로 그대로 보존합니다. 0을 제거하거나 평균으로 바꾸면 늦은 시간대와 저수요 역의 패턴이 왜곡됩니다.

DUPLICATES

중복 0건, 합산 제거 0건

완전히 같은 행과 논리 키 중복 모두 0건이었습니다. 그래서 중복 제거라는 추가 변환은 수행하지 않았습니다.

AGGREGATION RULE

20개 시간대를 합쳐 하루를 정의합니다.

예측의 내부 목표 열 passengers는 한 원본 행에 들어 있는 시간대별 승하차 인원을 합산한 일일 승객 수입니다. 시간대별 값은 사라지지 않고, 하루의 리듬을 읽는 EDA에서 그대로 사용합니다.

이 점검이 필요한 이유

원본의 행 단위와 집계 단위를 혼동하면 같은 역을 두 번 세거나, 0명 기록을 누락으로 오해할 수 있습니다. 이 페이지의 수치는 이후 모든 차트와 모델의 공통 기준입니다.

CODE PATH

검증 규칙은 코드로 고정합니다.

화면의 감사 수치는 수동 입력이 아니라 데이터 생성 스크립트가 다시 계산한 결과입니다. 아래 함수가 각각의 규칙을 책임집니다.

01 / INGESTload_source()

02 / TARGETbuild_model_frame()

20개 시간대 합으로 일일 수요를 만들고, 역·노선·방향별 날짜순 lag·rolling 값을 생성합니다.

03 / PUBLISHmain()

감사 결과와 EDA·모델 결과를 site/generated/site_data.json으로 내보냅니다.

model['passengers'] = source[time_columns].sum(axis=1)
model['lag_7'] = grouped.shift(7)
model['rolling_7'] = grouped.transform(lambda x: x.shift(1).rolling(7, min_periods=7).mean())
