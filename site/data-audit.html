ROW GRAIN날짜 × 노선 × 역번호 × 방향

한 행은 한 역의 한 방향에 대한 하루 20개 시간대 기록입니다. 역명만으로 묶지 않고 역번호·노선·방향을 보존합니다.

NUMERIC SCOPE—개 시간대 셀

수치 품질 검사는 식별 열이 아니라 시간대 값 전체에서 수행합니다. 유효한 0명은 —개이며 삭제하지 않습니다.

TARGET RULE20개 시간대의 합 = 하루

예측의 정답 passengers는 20개 시간대의 합입니다. 시간대 값은 일별 예측의 입력이 아니라 시간 패턴 분석에 남깁니다.

AUDIT RESULT

원본은 분석 가능한가?

완전 빈 행만 제외합니다. 결측·음수·중복은 “지워야 할 값”이 아니라 먼저 원인을 확인해야 할 품질 신호이므로 결과를 따로 공개합니다.

01

LOAD

원본을 그대로 읽기

CP949 인코딩 CSV에서 날짜·노선·역번호·역명·방향과 20개 시간대 값을 읽습니다.

— physical rows— columns— time bands
02

BLANK-ROW RULE

완전히 빈 행만 제외

모든 열이 비어 있는 행만 원본 끝의 공백으로 판단합니다. 일부 값이 있는 행은 원본 정보로 취급해 보존합니다.

— removed— retained rows
03

NUMERIC CHECK

시간대 수치의 유효성 검사

20개 시간대 칸을 숫자로 변환해 결측·음수·0을 별도 점검합니다. 이번 파일에는 결측과 음수가 없어 수요 값을 대체하지 않았습니다.

— cells checked— missing— negative— valid zeros kept
04

KEY CHECK

중복 여부 확인, 임의 제거 없음

날짜·노선·역번호·역명·방향의 논리 키와 전체 행을 검사합니다. 중복은 원인을 확인하기 전에는 합치거나 제거하지 않습니다.

— duplicate rows— duplicate keys
05

TARGET BUILD

20개 시간대를 하루 수요로 합산

남은 각 원본 행의 시간대 합을 passengers로 만듭니다. 시간대 열 자체는 제거하지 않고 시간 리듬 분석에 유지합니다.

— daily targets1 target / line-station_code-direction-day
06

HISTORY WINDOW

28일 과거가 있는 행만 준비

가장 긴 입력이 lag_28이므로, 각 시리즈의 처음 28일은 수치로 채우지 않고 warm-up으로 제외합니다. 이는 미래를 보지 않기 위한 규칙입니다.

— series— warm-up excluded— feature-ready rows
07

TIME SPLIT

시간 순서대로 학습·검증·테스트

준비된 날짜를 앞 80%·다음 10%·마지막 10%로 나눕니다. 테스트의 모든 행은 그보다 앞선 기록만 볼 수 있습니다.

— train— validation— test predictions

DECISION RECORD

무엇을 제외하고 보존했나

물리적으로 비어 있는 행만 제외했습니다. 유효한 0명·정상 수치·시간대 열은 보존하며, 모델의 입력 행 감소는 결측 대체가 아닌 필요한 과거 이력 부족에서만 발생합니다.

이 점검이 필요한 이유

행 단위와 집계 단위를 혼동하면 같은 역을 두 번 세거나 0명 기록을 누락으로 오해할 수 있습니다. 이 페이지의 계약은 이후 모든 차트와 모델의 공통 전제입니다.

CODE PATH

검증 규칙은 코드로 고정한다.

화면의 감사 수치는 수동 입력이 아니라 데이터 생성 스크립트가 다시 계산한 결과입니다.

일일 목표를 만들고 역번호·노선·방향별 날짜순 lag와 rolling 입력을 생성합니다.

03 / PUBLISHmain()

감사·EDA·입력 프로파일·모델 결과를 site/generated/site_data.json으로 발행합니다.

model['passengers'] = source[time_columns].sum(axis=1)
grouped = model.groupby(['line', 'station_code', 'direction'])['passengers']
model['lag_7'] = grouped.shift(7)
model['rolling_7'] = grouped.transform(lambda x: x.shift(1).rolling(7, min_periods=7).mean())
