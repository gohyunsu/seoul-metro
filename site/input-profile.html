01 / CATEGORY COVERAGE

어떤 범주가
얼마나 나타나는가?

노선·역번호·방향은 숫자 크기를 뜻하지 않는 범주형 입력입니다. 원값의 순서를 학습시키지 않도록 one-hot으로 바꾸며, 여기서는 변환 전 범주가 가진 관측량과 복합도를 확인합니다.

LINE / DIRECTION COVERAGE

입력 행의 범주 분포

feature-ready rows

STATION_CODE COVERAGE

역번호는 273개 범주

역번호 하나가 여러 노선·방향 시리즈에 나타날 수 있습니다. 오른쪽 분포는 ‘동일 역번호에 연결된 시리즈 수’이며, 역명 빈도나 지리적 밀도가 아닙니다.

해석

범주 수가 많다는 사실만으로 과적합을 뜻하지는 않습니다. 그래서 인코더는 학습 구간에서만 적합하고, validation/test에 처음 나온 범주는 무시하도록 처리합니다. 상세한 범주형 변환 규칙은 Forecast 페이지의 feature ledger와 연결됩니다.

02 / CALENDAR PROFILE

미리 아는 날짜 정보가
수요와 만나는 방식

요일과 ISO 주차는 목표일 전에 확정되는 두 달력 입력입니다. 조건부 목표 통계와 실제 입력값 빈도를 분리해, 수요 차이와 표본 수 차이를 혼동하지 않게 합니다.

WEEKDAY × TARGET

요일별 시리즈-일 평균 수요

mean passengers

ISO WEEK × TARGET

주차별 중앙 수요의 흐름

median passengers

ISO WEEK FREQUENCY

모델에 들어간 주차 값의 실제 행 수

feature-ready rows

첫 28일을 warm-up으로 제외했기 때문에 W02–W04가 없고, 연말의 ISO W01은 일부 날짜만 포함합니다. 이는 달력 입력 불균형이지 결측 대체 결과가 아닙니다.

과거 수요 다섯 값의

ALL HISTORY VALUES

각 선의 합은 100%입니다. x축은 원래 승객 수를 공통 로그 간격으로 나눴고 pooled P99.5 이상은 마지막 칸에 모았습니다. 목표값은 입력이 아니며 비교용 점선입니다.

ROW-LEVEL SAMPLE

lag₇와 목표값의 개별 행 관계

2,600 deterministic rows

고정 난수 42로 뽑은 2,600행이며 축은 전체 P99.5에서 잘랐습니다. 주황 점선에 가까울수록 7일 전 값이 실제값과 같습니다.

Pearson 상관은 선형 동행 정도만 나타냅니다. 서로 겹치는 lag들은 상관이 높아도 독립적인 효과를 뜻하지 않습니다.

04 / MULTIVARIATE STRUCTURE

입력끼리 얼마나 겹치고,
목표와 함께 움직이는가?

요일·주차·다섯 history 입력·목표값의 모든 쌍을 같은 feature-ready 모집단에서 계산합니다. 짙은 history 블록은 비슷한 과거 신호가 여러 열에 중복됨을 보여줍니다.

PEARSON CORRELATION MATRIX

8개 수치 열의 쌍별 선형 관계

all feature-ready rows

초록은 양의 상관, 주황은 음의 상관입니다. 범주형 line·station_code·direction은 임의 숫자로 바꾸지 않으므로 이 행렬에서 제외합니다.

05 / SPLIT STABILITY

시간 분할을 건너도
분포가 급변하는가?

학습·검증·테스트는 무작위 행이 아니라 연속된 시간 구간입니다. 분위수 선과 정확한 감사표로 중앙과 양쪽 꼬리의 이동을 함께 비교합니다.

TARGET QUANTILES BY SPLIT

train · validation · test 분포 이동

P05 / P25 / P50 / P75 / P95
주의

분포가 같아 보인다고 미래 예측이 보장되지는 않습니다. 이 표는 누수 검사가 아니라 평가 구간의 규모 차이를 숨기지 않기 위한 보조 진단입니다. 누수 차단은 shift·시간순 분할·학습 구간 fit 규칙으로 별도로 수행합니다.

06 / MODEL DIAGNOSTIC

Ridge 후보는
어떤 열에 민감했는가?

validation에서 한 input 열만 무작위로 섞고 MAE가 얼마나 증가하는지 봅니다. 나머지 입력·모델·평가 행은 고정합니다. 이 그래프는 선택된 seasonal-naive의 중요도가 아니라, 비교 후보 Ridge의 의존성 진단입니다.

07 / SELECTED-BASELINE ERROR

선택된 기준선은
어디에서 흔들리는가?

최종 선택된 seasonal-naive의 테스트 오차를 목표일의 요일과 실제 수요 규모로 나눕니다. 실제 수요를 구간화하는 것은 예측 후 평가를 위한 것으로, 모델 입력에는 사용하지 않습니다.
