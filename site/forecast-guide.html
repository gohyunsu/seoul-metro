INPUT ADMISSION RULE

각 입력은 왜
통과했는가?

이 목록은 성능을 위해 가능한 값을 많이 넣은 것이 아니라, 예측 시점·중복성·시리즈 경계를 기준으로 최소 계약을 정한 기록입니다.

01 / SERIES IDENTITY

역명 대신 역번호를 사용

line + station_code + direction은 각 일별 시리즈를 유일하게 구분합니다. 역명은 화면에 보이도록 남기지만, 동명 표기 혼동을 막기 위해 모델 범주형 입력으로 쓰지 않습니다.

02 / KNOWN CALENDAR

요일과 ISO 주차만 유지

요일은 주간 운행·통근 리듬, ISO 주차는 느린 계절 변화를 나타냅니다. 월·일·연중일·주말 여부는 이 둘에서 중복되는 파생값이라 입력 계약에서 뺐습니다.

03 / PAST DEMAND

최근성·주간성·안정성을 분리

lag_1은 최근 변화, lag_7/14/28은 같은 요일의 반복, rolling_7은 직전 한 주의 평활한 수준을 봅니다. 모두 shift() 뒤 계산합니다.

04 / EXPLICITLY EXCLUDED

정답과 사후 정보는 차단

passengers(t)와 목표일의 20개 시간대는 입력이 아닙니다. 목표일이 지난 뒤에만 확인되는 값도 입력 후보에서 제외하며, 각 열은 예측 직전에 실제로 확보 가능한지 먼저 검증합니다.

MODEL & RESULT

동일한 입력으로
세 가지를 비교한다.

복잡성 자체가 목표가 아니므로, 설명 가능한 기준선부터 선형 모델, 비선형 부스팅 순서로 같은 입력·분할·지표에서 비교합니다.

01 / SELECTED

Seasonal naive

주간 반복 기준선 · 학습 없음

ŷt = yt−7

같은 노선·역번호·방향 시리즈의 7일 전 수요를 그대로 예측값으로 씁니다. 이 데이터의 주간 반복을 이기는지가 모든 후보의 통과 기준입니다.

02 / LINEAR

Ridge regression

one-hot + 표준화 + L2 정규화

min ‖y − Xβ‖² + α‖β‖²

고정 식별값은 one-hot, 수치형 입력은 표준화한 뒤 선형 관계를 추정합니다. alpha=10으로 계수가 과도하게 커지는 것을 억제합니다.

03 / NON-LINEAR

HistGradientBoosting

one-hot + 히스토그램 부스팅

120 trees · lr 0.08 · 31 leaves

범주형 값에 임의 순서를 부여하지 않도록 같은 one-hot 표현을 받아, 입력 간 비선형 상호작용을 학습합니다.

MODEL BENCHMARK

테스트 기간의 결과

TEST PERIOD

MAE는 평균 절대 오차(명), RMSE는 큰 오차 점검, WAPE는 전체 실제 수요 대비 오차 비율입니다.

CURRENT DECISION

—

선택은 validation MAE로만 했습니다. 테스트에서는 평균 —명·전체 수요의 — 오차로 확인합니다. 복잡한 모델이 이 기준선을 넘지 못한 것도 유효한 결론입니다.

해석의 범위

이 결과는 주간 반복의 예측력을 뜻하며, 수요 변화의 원인이나 실제 혼잡도를 판정하지 않습니다.

VALIDATION VS. TEST

선택과 최종 성적을 분리

두 기간 모두 낮을수록 좋습니다. 테스트는 선택 과정에 다시 사용하지 않습니다.

METRIC GUIDE

숫자를 어떻게
읽는가?

단일 점수로 모델을 과장하지 않기 위해, 선택 지표와 보조 지표가 다른 종류의 오차를 보도록 분리합니다.

MAE / SELECTION

평균적으로 몇 명 차이 났나

MAE = mean(|actual − prediction|)

승객 수 단위로 바로 읽히므로 validation에서 모델 선택의 주지표로 씁니다.

RMSE / LARGE ERROR

큰 실패에 더 민감한가

RMSE = √mean((actual − prediction)²)

드물지만 큰 오차가 있을 때 더 빨리 커집니다. MAE와 함께 큰 실패를 점검합니다.

WAPE / NETWORK SCALE

전체 수요 대비 오차 비율

WAPE = Σ|actual − prediction| / Σ|actual|

절대 오차 합을 전체 실제 수요로 나눠 네트워크 규모에서 해석합니다.

sMAPE / RELATIVE CHECK

저수요 구간의 상대 오차

sMAPE = mean(2|a − p| / (|a| + |p|))

실제값과 예측값 모두를 분모에 두는 보조 상대오차입니다. 0 분모는 0으로 처리합니다.

LEAKAGE GUARD

‘내일’이라는 말이
성립하는 네 가지 규칙

어느 하나라도 어기면 과거 성능은 좋아 보여도 실제 예측에서 재현되지 않습니다.

01 / KEY FIRST
line + station_code + direction으로 시리즈를 분리한 뒤 날짜순으로 정렬합니다. 다른 역이나 방향의 수요를 섞지 않습니다.
02 / SHIFT FIRST
모든 lag와 이동평균은 shift(1) 이후에 계산합니다. rolling_7(t) 안에 passengers(t)가 들어갈 수 없습니다.
03 / TARGET BLOCK
목표일 실제 수요와 20개 시간대 값은 입력에서 제외합니다. 목표일 이후에 확정되는 모든 정보도 같은 원칙으로 차단합니다.
04 / FIT & HOLDOUT
인코더와 스케일러는 학습 구간에서만 fit하고, 모델 선택은 validation, 최종 보고는 마지막 test 구간으로 분리합니다.
