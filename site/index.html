05 / PREDICTION ALGORITHMS

단순한 기준선부터
비선형 모델까지.

후보 모델은 같은 목표·입력·시간 분할을 공유합니다. 모델이 복잡하다는 이유로 선택하지 않고, 검증 MAE가 가장 낮을 때만 다음 후보로 채택합니다.수식·하이퍼파라미터·코드 경로 ↗

01 / BASELINE

Seasonal naive

ŷt = yt−7

같은 시리즈의 일주일 전 수요를 그대로 사용합니다. 학습이 없는 기준선이지만 강한 주간 반복을 직접 반영합니다.

02 / LINEAR

Ridge regression

‖y−Xβ‖² + 10‖β‖²

one-hot 범주와 표준화한 수치 입력의 선형 결합을 학습하고 L2 규제로 계수의 폭주를 줄입니다.

03 / NON-LINEAR

HistGradientBoosting

120 iter · lr .08 · 31 leaves

잔차를 순차적으로 줄이는 트리 앙상블로 입력 간 비선형 상호작용을 학습합니다.

04 / SELECTION RULE

Validation first

min validation MAE

검증 구간으로 모델을 고르고, 마지막 테스트 구간은 선택 이후의 일반화 성능 보고에만 사용합니다.

RESULT INTERPRETATION

“단순한 모델이 이겼다”가 아니라, 7일 주기가 가장 안정적인 신호였다.

Ridge와 부스팅은 더 많은 입력 관계를 학습했지만 검증 구간에서 7일 반복 기준선을 넘지 못했습니다. 따라서 현재 데이터와 분할에서는 복잡도를 늘릴 근거가 없습니다.

VALIDATION VS. TEST

선택 점수와 최종 보고를 분리

validation은 선택에, test는 선택된 절차의 마지막 확인에만 사용합니다. 두 구간의 순위가 다르면 선택 규칙은 바꾸지 않습니다.

MAE평균 절대 오차

mean(|y−ŷ|). 한 행당 평균적으로 몇 명을 빗나갔는지 보여주어 모델 선택에 사용합니다.

RMSE제곱근 평균제곱오차

√mean((y−ŷ)²). 큰 오차에 더 큰 벌점을 주어 실패 사례의 크기를 점검합니다.

WAPE총량 가중 절대오차

Σ|y−ŷ| / Σ|y|. 서로 다른 수요 규모를 전체 실제 수요 대비 비율로 요약합니다.

sMAPE대칭 평균 절대비율오차

mean(2|y−ŷ|/(|y|+|ŷ|)). 0 근처에서는 민감하므로 보조 지표로만 사용합니다.

결론의 사용 범위

선택된 기준선은 평상시 수요의 빠른 비교점과 watchlist를 만드는 데 유용합니다. 개별 날짜의 원인을 설명하거나 실제 혼잡도를 보장하지 않으며, 높은 오차 구간은 요일·수요 규모별 진단에서 따로 확인합니다.
