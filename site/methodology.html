REPRODUCIBLE PATH

원본에서 해석까지

각 단계는 앞선 단계의 가정을 숨기지 않도록 분리했습니다. 숫자가 바뀌면 정적 문장만 고치는 대신, 집계 데이터와 화면을 다시 생성하는 흐름입니다.

Source

서울 열린데이터광장 OA-12921의 서울교통공사 관할 1–8호선 일별·시간대별 승하차 기록을 사용합니다. 출처와 스냅샷 기간을 화면에 명시합니다.

Audit

물리 행, 완전 빈 행, 결측 셀, 음수, 중복 논리 키, 시간대 수를 확인합니다. 완전 빈 행만 제외하고 유효한 0명 값은 보존합니다.

Transform

원본의 20개 시간대를 보존한 long view로 EDA를 수행하고, 예측용으로는 같은 행의 시간대 합계인 passengers를 만듭니다.

Explore

일별 총량, 요일·시간대, 노선 기여, 상위 역, 승차·하차 방향, 고·저수요일을 비교해 예측 과제와 기준선의 근거를 만듭니다.

Evaluate

날짜순으로 train/validation/test를 나누고, seasonal-naive·Ridge·HistGradientBoosting을 같은 기간과 지표로 비교합니다.

Publish

수치뿐 아니라 대상 단위, 집계 규칙, 평가 방법, 해석 한계를 연결해 누구나 결과의 적용 범위를 확인할 수 있게 합니다.

CODEBASE MAP

어느 파일이 무엇을 만드는가?

재현은 설명 문서만으로 끝나지 않습니다. 원본·계산·산출물·화면 사이의 책임을 나눠, 값이 바뀌었을 때 어디를 다시 실행해야 하는지 알 수 있게 합니다.

RAW INPUTdata/raw/seoul_metro_ridership_2025.csv

원본 스냅샷입니다. 분석 코드는 이 파일을 읽되, 파일 자체를 수정하지 않습니다.

COMPUTEscripts/build_site_data.py

감사, EDA 집계, 시계열 특징, 세 모델의 학습·평가, 보고용 그림 생성을 한 번에 수행합니다.

PUBLISHsite/generated/site_data.json

브라우저가 읽는 숫자 계약입니다. HTML과 JavaScript는 이 파일을 표시하고 상호작용을 더합니다.

./.venv/bin/python scripts/build_site_data.py
python -m http.server 8000 --directory site
# then open the local site and inspect regenerated values

WHAT THE DATA CANNOT SAY

해석의 바깥선

아래 항목은 결과가 쓸모없다는 뜻이 아니라, 수요 변화의 원인을 단정하거나 운영 결정을 자동화할 수 없다는 뜻입니다.

EXTERNAL CONTEXT

원인을 분리할 수 없습니다.

날씨, 행사, 공휴일의 세부 유형, 운행 장애, 역세권 변화, 환승량이 이 원본에 없습니다. 특정 날짜의 급증·급감에 대한 인과 설명에는 추가 데이터와 검증이 필요합니다.

AGGREGATED RECORD

개인의 이동을 말하지 않습니다.

데이터는 집계된 승하차 기록입니다. 개인의 경로나 체류, 환승 목적, 사회적 속성을 추론하는 데 사용해서는 안 됩니다.

FORECAST USE

예측은 약속이 아닙니다.

예측값은 평소 패턴과 다른 수요를 먼저 검토하기 위한 계획 보조 신호입니다. 실제 배포에는 서비스 변경 감시, 데이터 드리프트 점검, 외부 맥락의 추가가 필요합니다.

COMPARISON

한 지표로 승부를 가리지 않습니다.

큰 역은 절대 오차도 커지기 쉽고, 저수요 구간은 비율 오차가 커지기 쉽습니다. 전체 MAE·RMSE·WAPE와 세그먼트별 결과를 함께 확인합니다.

출처와 이용 고지

원자료는 서울 열린데이터광장에 공개된 데이터입니다. 원자료와 파생 결과를 이용·배포할 때에는 출처 표기와 원자료의 이용 조건을 확인해야 합니다. 원자료 페이지 열기 ↗
