EPOCH 1 / RESEARCH NOTE

From source file
to trusted record.

The 2025 public file is the foundation of both studies. We documented its physical rows, removed only completely empty rows and checked the logical keys before drawing conclusions.

SOURCE FILE

199,424 physical rows

The annual file contains 26 columns and covers 365 dates in 2025. Its original encoding is CP949.

CLEANING

134 empty rows removed

That leaves 199,290 valid records. Genuine zero-passenger counts remain in the dataset.

QUALITY CHECKS

No negative counts or duplicate keys

After blank-row removal, the audit found 243 stations, eight lines and 20 source time bands.

These are source-file audit counts. The hourly forecast uses 18 regular service-hour targets; the irregular edge aggregates are not prediction targets.
