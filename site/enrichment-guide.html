날씨는 어떤 입력으로 들어갔나?

8개 관측값은 서울 단일 관측소의 날짜별 공통 신호입니다. snwd는 350일 결측이라 후보에서 제외했고, 강수량의 11개 결측은 0 mm로 보수적으로 채웠습니다.

ADDRESS FEATURE CONTRACT

주소에서 어떤 공간 정보를 만들었나?

주소 전문을 모델에 그대로 넣지 않고, 설명 가능한 행정구·시도 범주와 위도·경도만 추출했습니다. 역명이 이미 모델에 있으므로 주소는 새로운 역 정체성이 아니라 공간적 일반화 신호를 시험하는 역할입니다.

station_key = normalize(station)
station_key = historical_alias(station_key)
join_key = ['line', 'station_key']
address_district = station_address.extract(r'([가-힣]+구)')
features += ['address_district', 'address_region', 'station_lat', 'station_lng']

KRIC 캐시는 2026년 참조 데이터이므로, 2025년의 역명 변경 사례를 명시했고 과거 시점에 존재하지 않았을 수 있는 최신 메타데이터가 섞일 위험은 한계로 기록합니다. 수요 원본의 모든 역×노선 조합이 결합된 경우에만 실험을 실행합니다.

SAME SPLIT, ACTUAL RESULTS

개선은 있었지만, 채택되지는 않았습니다.

숫자가 낮을수록 좋습니다. 변화율은 동일한 HGB 대비 테스트 MAE의 변화이며, 양수는 개선입니다. 최종 운영 기준선은 여전히 Seasonal naive입니다.

해석의 순서

전날 날씨를 더하면 기존 HGB보다 오차가 낮아졌습니다. 하지만 이 데이터에서는 7일 전 같은 시리즈를 쓰는 계절 기준선이 더 낮은 검증 MAE를 보였습니다. 따라서 외부변수의 ‘트리 모델 내 개선’과 ‘운영 모델 채택’을 구분해 기록합니다.

WHY THE RESULT IS PLAUSIBLE

주소와 날씨가 만능 입력이 아닌 이유

성능의 크기는 변수의 흥미로움보다, 예측 시점의 가용성·해상도·기준선이 이미 설명하는 신호의 양에 좌우됩니다.

ADDRESS

역명과 중복되는 고정 특성

기준 모델은 이미 station을 범주형으로 받습니다. 같은 역의 상시 수요 규모와 상당수 공간 차이는 이 열에 포함되므로, 행정구·좌표가 추가 이득을 보장하지 않습니다.

WEATHER

하루·도시 단위의 거친 신호

서울 한 지점의 일별 날씨는 미시적인 역세권 차이, 행사·공휴일·운행 장애를 설명하지 못합니다. 운영 시점에는 실제 날씨가 아닌 예보 오차도 추가됩니다.

BASELINE

주간 반복이 매우 강함

동일 역·노선·방향의 7일 전 수요는 같은 요일·유사한 통근 리듬을 직접 담습니다. 새 신호는 이 강한 기준을 넘어야만 채택할 이유가 생깁니다.
