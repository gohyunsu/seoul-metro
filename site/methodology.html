REPRODUCIBLE PATH

원본에서 결론까지
여섯 단계

각 단계는 다음 단계가 받을 입력과 보장해야 할 조건을 명시합니다. 중간 산출물이 달라지면 어느 단계에서 차이가 생겼는지 역추적할 수 있습니다.

01 · Source

2025년 서울교통공사 관할 1–8호선의 역별·일별·시간대별 승하차 원본을 CP949로 읽습니다. 파일 자체는 수정하지 않습니다.

02 · Audit

물리 행, 완전 빈 행, 날짜 범위, 20개 시간대, 결측, 음수, 0, 전체 행 중복과 논리 키 중복을 각각 기록합니다.

03 · Understand

시간대 값을 날짜·요일·노선·역·방향으로 집계하되, 각 차트의 분모와 평균 단위를 따로 명시합니다.

04 · Feature

일일 목표를 만든 뒤 line + station_code + direction 안에서만 날짜순 shift와 이동평균을 계산합니다.

05 · Evaluate

연속된 날짜를 80/10/10으로 분리하고 validation MAE로 모델을 선택합니다. 마지막 test는 선택 이후 한 번만 보고합니다.

06 · Publish

감사표, 입력 프로파일, 모델 지표와 차트 배열을 JSON으로 생성합니다. HTML은 숫자를 하드코딩하지 않고 이 계약을 렌더링합니다.

WHAT THE DATA CANNOT SAY

해석의 바깥선

한계는 결과를 약화하는 각주가 아니라, 결과를 어디까지 사용할 수 있는지 정하는 계약입니다.

SINGLE-YEAR WINDOW

연도 간 일반화를 검증하지 않았습니다.

2025년 한 해만 사용하므로 장기 추세와 연도별 구조 변화가 분리되지 않습니다. 현재 성능은 같은 해의 후반 기간에 대한 holdout 결과입니다.

AGGREGATED RECORD

개인의 이동을 추론하지 않습니다.

자료는 역·노선·방향·시간대 단위의 집계치입니다. 개인 경로, 체류, 환승 목적이나 사회적 속성을 설명하지 않습니다.

UNOBSERVED CONTEXT

특정 날짜의 원인을 단정하지 않습니다.

공휴일 세부 유형, 대형 행사, 운행 장애, 공사와 서비스 변경은 입력에 포함되지 않았습니다. 급증·급감은 관찰 사실이지 원인 판정이 아닙니다.

POINT FORECAST

예측값은 확정 수요가 아닙니다.

현재 출력은 한 개의 점 추정치입니다. 실제 운영에는 예측 구간, 초과 확률, 오류 비용과 담당자 검토 절차가 추가되어야 합니다.

ONE HOLDOUT

한 번의 분할에 민감할 수 있습니다.

마지막 10% 테스트는 정직한 최종 구간이지만, 여러 기준점을 이동하는 rolling-origin 평가가 있어야 기간 의존성을 더 잘 판단할 수 있습니다.

SPATIAL OVERLAY

지도는 상위 10개 역의 상대 비교입니다.

열레이어는 모든 역의 연속적 수요면이나 이동 경로가 아닙니다. 상위 역 대표점의 규모와 공간적 집중만 보여줍니다.
